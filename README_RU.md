# MediLens AI — учебный прототип

MediLens AI — тёмный веб-интерфейс для демонстрации классификации синтетических лабораторных данных, связанных с анемией.

## ВАЖНО
**Это не медицинский инструмент.** Встроенный набор содержит только искусственно сгенерированные данные, а метки созданы упрощённым учебным правилом. Модель не обучалась на реальных пациентах и не предназначена для диагностики, скрининга, рекомендаций по лечению или принятия медицинских решений. Метрики в `models/metrics.json` отражают только воспроизведение искусственных меток.

## Что входит
- `app.py` — сайт на Streamlit.
- `train_model.py` — воспроизводимый скрипт обучения.
- `data/demo_synthetic_blood_data.csv` — 1 800 синтетических строк.
- `models/medilens_model.joblib` — сохранённая обученная модель.
- `models/metrics.json` — фактические результаты тестирования.

## Запуск на компьютере (Windows)
1. Установите Python 3.11 или 3.12 с сайта https://www.python.org/downloads/ и при установке отметьте **Add Python to PATH**.
2. Распакуйте ZIP-архив в папку, например `Desktop\MediLens_AI`.
3. Откройте эту папку в Проводнике.
4. Щёлкните по адресной строке папки, напишите `cmd` и нажмите Enter.
5. В открывшемся окне выполните команды по одной:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

6. Через несколько секунд сайт откроется в браузере. Если нет — скопируйте адрес `http://localhost:8501` в браузер.

## Запуск на macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

## Повторное обучение модели
Из корневой папки проекта после установки зависимостей выполните:
```bash
python train_model.py
```
Скрипт заново обучит модель на приложенном CSV, рассчитает метрики на отдельной тестовой выборке и обновит файлы в `models/`.

## Публикация в интернете
1. Создайте репозиторий GitHub и загрузите содержимое этой папки.
2. Откройте https://share.streamlit.io/ и войдите через GitHub.
3. Создайте приложение, выберите репозиторий и файл `app.py`.
4. Укажите ветку `main`, главный файл `app.py` и нажмите Deploy.

Для публичной версии обязательно сохраните предупреждение об учебном характере модели. Не загружайте настоящие персональные или медицинские данные.

## Интерпретация метрик
`accuracy`, `precision`, `recall` и `F1-score` вычисляются по синтетической отложенной выборке. Даже очень высокие значения не свидетельствуют о клинической точности, поскольку обучающие метки искусственные и зависят от заданных правил.
